# Droneburg Valheim Modpack v1.1.0

Valheim 1.0.14 / Deep North rebuild.

## Major changes

- Updated shared/server/client mod stack.
- Added HaulersHelper 1.0.4.
- TidyChests updated to custom 1.2.1 Droneburg build.
- TidyChests stash/find radius locked to 90 meters.
- TidyChests browser scan radius locked to 90 meters.
- Reduced cart cargo-weight contribution to 10%.
- Removed cultivated-ground requirement for planting.
- Disabled plant grow-space restriction.
- Removed unwanted Splash_WaterEmerge01 sound.
- Added persistent server mod restoration.
- Added validation gates for future automated releases.

- EquipmentAndQuickSlots 3.1.3

## Install

Download the installer attached to this release and run it.

The installer automatically locates common Steam Valheim installations. If needed, select the Valheim installation folder manually.

Existing BepInEx files are backed up before the Droneburg package is installed.
